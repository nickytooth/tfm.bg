# Деплой на TFM сайта в SuperHosting (статичен)

Сайтът е Next.js със **статичен експорт** — генерира папка `out/`, която се качва на споделения хостинг (Apache). Контактната форма работи през `contact.php` (праща на office@tfm.bg).

## 1. Генериране на сайта (на твоя компютър)

```bash
npm install        # само първия път
npm run build
```

Това създава папка **`out/`** с целия готов сайт.

## 2. Качване в SuperHosting

Качи **СЪДЪРЖАНИЕТО на `out/`** (не самата папка) в `public_html/` на домейна:

- През **cPanel → File Manager** (или FTP).
- ВАЖНО: включи показването на скрити файлове (Settings → Show Hidden Files), за да се качат `.htaccess` и `contact.php` — те са вътре в `out/`.
- Качи всичко: `_next/`, `bg/`, `en/`, `img/`, `404.html`, `favicon.ico`, `.htaccess`, `contact.php`.

## 3. Настройки в хостинга (еднократно)

1. **SSL**: пусни Let's Encrypt в cPanel за домейна, преди да разчиташ на HTTPS пренасочването в `.htaccess`.
2. **Имейл**: увери се, че пощенската кутия **office@tfm.bg** съществува (формата праща там).
3. Отвори сайта — `tfm.bg` автоматично пренасочва към `/bg/`.

## 4. Тествай формата

Изпрати пробно запитване от `/bg/contact/`. Трябва да пристигне на office@tfm.bg.

Ако имейлите не идват (някои хостинги ограничават PHP `mail()`):
- Провери в cPanel дали `mail()` е разрешен / погледни папка spam.
- Алтернатива: мога да пренапиша `contact.php` да праща през **Resend API** (по-сигурна доставка) — само трябва Resend ключ.

## 5. Бъдещи промени

При всяка промяна на съдържание/дизайн:
```bash
npm run build
```
и качи наново съдържанието на `out/` (презапиши).

---

**Бележки**
- Всички анимации/ефекти работят (те са client-side JavaScript).
- `From` адресът на формата е `noreply@tfm.bg`, `Reply-To` е имейлът на подателя (отговаряш директно).
- Езиците: `/bg/` (по подразбиране) и `/en/`.
